# BAI 작업 핸드오프 공유

BAI 소모임원들이 각자 AI 에이전트(Claude Code/Codex 등)로 작업한 맥락을, 회의 없이도 짧은 문서 한 장으로 서로 넘기기 위한 저장소입니다.

## 사용 방법

1. 이 저장소를 `git clone` 받습니다 (한 번만).
2. 세션을 마칠 때, [template.md](template.md)를 복사해서 `핸드오프/` 폴더 아래 새 파일로 저장합니다. (파일명 예: `2026-09-09-크롤링-핸드오프.md`)
3. 대괄호 `[ ]` 부분을 실제 내용으로 채웁니다.
4. `git add`, `git commit`, `git push`로 올립니다.
5. 팀원은 `git pull`로 최신 문서를 받아서 읽고, 자기 AI 에이전트 대화창에 붙여넣어 이어서 작업합니다.

## 원칙

- 원본 대화를 통째로 붙여넣지 않습니다. 노이즈가 많아서 상대방 AI가 핵심을 못 고릅니다. 반드시 템플릿 항목별로 걸러서 요약합니다.
- 무거운 코드/데이터 자체는 여기 올리지 않습니다. "결과물 위치" 항목에 원래 프로젝트의 경로나 링크만 적습니다.
